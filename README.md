# Site Baterminas

`EMPRESA` Baterminas

`STACK` Next.js • React • TypeScript • Tailwind CSS

`URL` [baterminas.com.br](https://baterminas.com.br)

Site institucional da Baterminas, desenvolvido em Next.js, reunindo informações sobre os serviços, produtos e formas de contato da loja.

---

## 🚀 Como executar localmente

### Pré-requisitos
- Node.js (versão 18 ou superior)
- Gerenciador de pacotes (`npm`, `yarn`, `pnpm` ou `bun`)

### Passo a passo

1. Clone o repositório:
```bash
git clone https://github.com/pedrosiqueirapb/baterminas-site.git
```

2. Instale as dependências:
```bash
npm install
```

3. Inicie o servidor de desenvolvimento:
```bash
npm run dev
```

4. Acesse no navegador:
```bash
http://localhost:3000
```

## 🛠️ Tecnologias utilizadas

- **Framework:** [Next.js](https://nextjs.org/)
- **Linguagem:** TypeScript

- **IDE:** Google Antigravity

---

## 📌 Principais recursos

- **Apresentação de serviços:** Divulgação dos serviços oferecidos pela Baterminas, com acesso direto aos canais de atendimento.
- **Catálogo de marcas:** Exibição das marcas de baterias comercializadas pela loja.
- **Tipos de bateria:** Apresentação das categorias de baterias disponíveis na loja.
- **Painel administrativo:** Gerenciamento dos conteúdos exibidos no site, com opções de cadastro, edição e exclusão.
